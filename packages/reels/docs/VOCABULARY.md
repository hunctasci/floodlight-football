## Worlds

### `football` (3d)

Canonical HNC stadium with a deterministic choreography; cast mapped onto roles.

Params (`set`): `moment` — Choreography id (hero-attack); `roles` — Cast id per role, e.g. { striker: "hero", rival: "rival" } (hero-attack roles: striker, rival, keeper, mate, holder)

Subjects: `goal-away`, `centre-spot`, `floodlight (light)`, `floodlight-near (light)`, `floodlight-home (light)`, `floodlight-home-near (light)`

World lenses / moves: `wide`, `ball-rise-reveal`, `faceoff-depth-push`, `runner-burst`, `runner-lead`, `runner-approach`, `striker-windup`, `net-reverse`, `scorer-push`, `crane-out`, `stadium-drift`, `ball-hero-low`, `faceoff-depth-wide`, `faceoff-depth-tight`, `runner-follow`, `runner-lead-close`, `striker-windup-tight`, `net-reverse-close`, `scorer-low`, `scorer-low-tight`, `stadium-high`, `stadium-high-drift`

Ambience bed: `crowd-bed`

Moment `hero-attack`: roles `striker`, `rival`, `keeper`, `mate`, `holder`; beats `moment:kickoff`, `moment:slide`, `moment:hopStart`, `moment:hopEnd`, `moment:windup`, `moment:contact`, `moment:keeperDive`, `moment:goalLine`, `moment:netHit`, `moment:celebrate`, `moment:mateArrive`, `moment:touch-1`, `moment:touch-2`, `moment:touch-3`, `moment:touch-4`, `moment:touch-5`, `moment:touch-6`

### `office` (3d)

Open-plan office pod: two facing desks dressed with the owners’ country clues, coworkers, fluorescent lights.

Params (`set`): `clock` — Wall clock text (default "09:03"); `extras` — Background coworkers 0..6 (default 5); `screens` — Monitor content per surface, e.g. { "desk-b-monitor": "hnc-live" } (default spreadsheet); `clues` — Dress desks with owner country flag + mug (default true)

Marks: `desk-a` (sit), `desk-b` (sit), `aisle` (stand), `door` (stand), `coffee-machine` (stand), `pod-left-a` (sit), `pod-left-b` (sit), `pod-right-a` (sit), `pod-right-b` (sit), `pod-back-a` (sit), `pod-back-b` (sit)

Subjects: `desk-a-flag`, `desk-b-flag`, `desk-a-mug`, `desk-b-mug`, `desk-a-keyboard`, `desk-b-keyboard`, `pod-centre`, `wall-clock`, `ceiling-light (light)`, `desk-a-monitor (screen)`, `desk-b-monitor (screen)`

World lenses / moves: `wide`, `wide-reverse`, `pod-high`

Ambience bed: `office-tone`

World effects: `lights-flicker`, `lights-surge`, `coworkers-look`

### `studio` (3d)

Sports-news studio: anchor desk, two anchor seats, wall screen with HNC content.

Params (`set`): `screen` — Wall screen content (hnc-news, breaking, world-table, hnc-live, hnc-logo, spreadsheet, off; default "hnc-news"); `home` — Country shown on country-aware screens (default: first cast member); `away` — Rival country for country-aware screens

Marks: `anchor-left` (sit), `anchor-right` (sit), `exit-right` (stand), `exit-left` (stand), `presenter` (stand)

Subjects: `mug-left`, `mug-right`, `desk-logo`, `key-light (light)`, `rig-left (light)`, `rig-right (light)`, `studio-screen (screen)`

World lenses / moves: `wide`, `desk`, `screen`, `jib`

Ambience bed: `studio-tone`

### `phone` (2d)

Messaging app: group chat thread with HNC-character avatars, typing dots, push notification banner.

Params (`set`): `title` — Chat name (e.g. "the boys ⚽"); `me` — Cast id whose messages are sent (right side); `members` — Cast ids in the chat header; `time` — Status-bar clock (default "23:47"); `thread` — Thread id shared by phone scenes that continue one chat (default: scene id)

Ambience bed: `room-tone`

### `title` (2d)

HNC-branded plate (menu backdrop, pitch-line motif) for typography and end cards.

Params (`set`): `theme` — night | pitch | gold (default night)

## Transitions

| type | default s | what it does |
|---|---|---|
| `cut` | 0 | Hard cut |
| `match-cut` | 0 | Hard cut between matched framings (same lens, new world) |
| `flash` | 0.2 | White flash across the cut |
| `dip` | 0.5 | Dip to black |
| `light-bloom` | 0.6 | A light in the outgoing shot blows out to white; the frame resolves from a light in the incoming shot (needs `from`: light) (needs `to`: light) |
| `whip-pan` | 0.34 | Both cameras whip sideways; the cut hides in the blur |
| `zoom-through` | 0.55 | Push into a screen (phone notification, monitor, studio wall): the next shot is inside it (needs `from`: surface) |
| `wipe` | 0.4 | A dark foreground shape sweeps the lens and reveals the next shot behind it |
| `cloud-puff` | 0.7 | Cartoon cloud puff hides the swap (tie flies off, ball appears) |
| `glitch` | 0.3 | Broadcast glitch: RGB slices tear across the cut |
