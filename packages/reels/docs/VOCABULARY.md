## Worlds

### `football` (3d)

Canonical HNC stadium with a deterministic choreography; cast mapped onto roles.

Params (`set`): `moment` — Choreography id (hero-attack, hero-attack-bar, free-kick, midnight-penalty, walk-out); `roles` — Cast id per role, e.g. { striker: "hero", rival: "rival" } (roles per moment: see Moments below); `light` — day | night | dawn | horror (default day: the canonical game rig); `crowd` — full | empty (default full); `dropBall` — Moment second the ball lands from a referee drop (falls from above before it); `tifo` — Country code of a cloth tifo over the far terraces (e.g. "TR"); `home` — Home country when no cast plays a home role (default TR); `away` — Away country when no cast plays an away role (default GR); kits resolve clashes with the game rule

Subjects: `goal-away`, `centre-spot`, `floodlight (light)`, `floodlight-near (light)`, `floodlight-home (light)`, `floodlight-home-near (light)`

World lenses / moves: `wide`, `ball-rise-reveal`, `faceoff-depth-push`, `runner-burst`, `runner-lead`, `runner-approach`, `striker-windup`, `net-reverse`, `scorer-push`, `ball-overhead-rise`, `crane-out`, `stadium-drift`, `ball-hero-low`, `faceoff-depth-wide`, `faceoff-depth-tight`, `runner-follow`, `runner-lead-close`, `striker-windup-tight`, `net-reverse-close`, `scorer-low`, `scorer-low-tight`, `goal-behind`, `spot-low`, `ball-overhead`, `ball-overhead-wide`, `fk-high`, `kick-behind`, `walkout-front`, `walkout-back`, `walkout-high`, `poster-horror`, `stadium-high`, `stadium-high-drift`

## Transitions

| type | default s | what it does |
|---|---|---|
| `cut` | 0 | Hard cut |
| `match-cut` | 0 | Hard cut between matched framings (same lens, new world) |
| `flash` | 0.2 | White flash across the cut |
| `dip` | 0.5 | Dip to black |
| `dissolve` | 1 | Slow cross-dissolve: both pictures share the frame (ceremony, memory — use sparingly) |
| `white-out` | 0.8 | Walk into the light: the frame burns to white, the next shot resolves out of it |
| `light-bloom` | 0.6 | A light in the outgoing shot blows out to white; the frame resolves from a light in the incoming shot (needs `from`: light) (needs `to`: light) |
| `whip-pan` | 0.34 | Both cameras whip sideways; the cut hides in the blur |
| `zoom-through` | 0.55 | Push into a screen (phone notification, monitor, studio wall): the next shot is inside it (needs `from`: surface) |
| `wipe` | 0.4 | A dark foreground shape sweeps the lens and reveals the next shot behind it |
| `cloud-puff` | 0.7 | Cartoon cloud puff hides the swap (tie flies off, ball appears) |
